# SvnDesk

macOS 向けの Subversion GUI クライアントです。SmartSVN の画面構成と操作体系を参考に、
Swift/SwiftUI でゼロから実装しています（SmartSVN のコード・画像・名称は使用していません）。
SVN 操作は内部で `svn` コマンドラインクライアントを呼び出します。

## 必要環境

- macOS 14 以降
- Subversion コマンドラインクライアント（例: `brew install subversion`）

## ビルド

```sh
./build_app.sh          # build/SvnDesk.app を生成（アドホック署名）
swift test              # 差分エンジン・XML パーサのテスト
```

## 主な機能

| 領域 | 内容 |
| --- | --- |
| プロジェクト | チェックアウト / 既存作業コピーを開く / インポート / ローカルリポジトリ作成（svnadmin） / プロジェクト一覧 |
| メイン画面 | ディレクトリツリー、ファイル一覧（名前・リビジョン・ローカル状態・リモート状態・変更セット・コピー元・相対ディレクトリ・作成者）、ファイルフィルタ、変更プレビュー、出力、トランザクション |
| 変更操作 | 更新（リビジョン/深さ指定）、スイッチ、リロケート、マージ（範囲 / 2 ソース / ドライラン）、パッチ適用、コミット（未管理ファイルの自動追加・欠落ファイルの自動削除・メッセージ履歴）、追加、除去、無視、物理削除（ゴミ箱）、ディレクトリ作成、名前変更、移動、コピー、元に戻す、解決済み、改行コード修正、クリーンアップ、バキューム |
| 照会 | 変更表示 / HEAD・前リビジョンとの比較（ユニファイド・左右並べ・コンパクト・空白/大文字小文字無視）、ログ（絞り込み・変更パスの差分）、注釈、パッチ作成、バックアップのエクスポート、リモート状態の更新 |
| 競合ソルバー | テキスト競合を 3-way（自分 / ベース / 相手）で表示。競合しない変更は自動採用、競合ごとに「自分・相手・自分→相手・相手→自分・ベース」を選択、結果は手動編集も可能。保存すると `svn resolve --accept working` |
| リビジョングラフ | trunk / branches / tags をレーンとして表示し、コピー（ブランチ・タグ作成）を矢印で接続。ブランチ名で絞り込み、ノード選択で詳細表示 |
| ログキャッシュ | リポジトリ全体のログを `~/Library/Application Support/SvnDesk/LogCache` に保存し差分だけ取得。ログ画面（コピー元の履歴も追跡）とグラフで使用。「ログキャッシュを管理…」で削除可能 |
| レビュー画面 | ツールバー右端で「メイン / レビュー」を切替（⌥⌘1 / ⌥⌘2）。変更ファイルを順に差分確認し、レビュー済みのものだけをコミット |
| ツールバー | 右クリックまたは「編集 ▸ ツールバーをカスタマイズ…」で項目の追加・削除・並べ替え（設定は保存されます） |
| その他 | 変更セット（changelist）、タグ/ブランチ作成、ロック/ロック解除/要ロック、プロパティ編集、リポジトリブラウザ、Finder サービス（SVN から更新 / SVN へコミット / SvnDesk で開く）、認証ダイアログ |

## 日本語化

UI はシステム言語に従って日本語/英語で表示されます。設定（⌘,）の「言語」で固定もできます（再起動後に反映）。
翻訳は `Sources/SvnDesk/L10n+ja.swift` にあり、キーは英語の原文です。

## 制限事項

- リビジョングラフはコピー関係のみを描画し、svn:mergeinfo によるマージの矢印は表示しません。
- 競合ソルバーはテキスト競合が対象です。ツリー競合・プロパティ競合は「解決済みにする」で処理します。
- ログキャッシュの初回作成ではリポジトリ全体の履歴を取得するため、大きなリポジトリでは時間がかかります（中断しても続きから再開します）。
